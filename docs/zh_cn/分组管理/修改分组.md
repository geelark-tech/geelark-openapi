## 接口说明


- 修改某个分组信息包括 name, remark


## 请求 URL


- `https://openapi.geelark.cn/open/v1/group/update`


## 请求方法


- POST



## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../使用指南/云手机/接口调用说明.md)）

## 请求参数


| 参数名 | 必选 | 类型         | 说明     | 示例         |
| ------ | ---- | ------------ | -------- | ------------ |
| list   | 是   | array[Group] | 分组数据 | 参考请求示例 |


### list 分组数据 <Group>


| 参数名 | 必选 | 类型   | 说明       | 示例         |
| ------ | ---- | ------ | ---------- | ------------ |
| id     | 是   | string | 分组 id    | 参考请求示例 |
| name   | 否   | string | 新分组名，最长50个字符   | 参考请求示例 |
| remark | 否   | string | 新分组备注，最长500个字符 | 参考请求示例 |


- 若携带 name，则 name 不能为空字符串


## 请求示例


```json
{
  "list": [
    {
      "id": "528995439832269824",
      "name": "newGroupRemark",
      "remark": "update remark"
    }
  ]
}
```


## 响应示例


```json
{
  "traceId": "B068F85E849B683291AE8ECCBB7B3DB9",
  "code": 0,
  "msg": "success",
  "data": {
    "totalAmount": 1,
    "successAmount": 1,
    "failAmount": 0
  }
}
```

| ------ | ---------------- |
