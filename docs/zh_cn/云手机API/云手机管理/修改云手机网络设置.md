## 接口说明

修改云手机网络设置，包括访问黑名单

### 访问黑名单

最多三个，设置后立即生效，云手机无法访问黑名单内域名

## 请求URL

- `https://openapi.geelark.cn/open/v1/phone/netConfig/set`

## 请求方法

- POST

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| blackList | 否 |  array[string] | 访问黑名单域名，不传则不更新，传空数组则置空 |


## 请求示例
```json
 {
	"blackList": ["c.com"]
}
```

## 响应示例

```json
{
    "traceId": "A62BBBF3A294487F9B49B9FFA0F84CA8",
    "code": 0,
    "msg": "success"
}
```
