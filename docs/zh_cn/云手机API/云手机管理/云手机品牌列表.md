## 接口说明

- 获取云手机品牌列表

## 请求URL

- `https://openapi.geelark.cn/open/v1/phone/brand/list`

## 请求方法

- POST


## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/云手机/接口调用说明.md)）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| androidVer | 是 | integer | 安卓版本，10-16 | 10 |

## 请求示例

```json
{
	"androidVer" : 10
}
```


## 响应示例

```json
{
	"traceId": "B0BA8FF29AB60B8ABF4E9A26BF08F7B9",
	"code": 0,
	"msg": "success",
	"data": [
		{
			"surfaceBrandName": "samsung",
			"surfaceModelName": "Galaxy S20+"
		}
	]
}
```

## 响应体数据说明

| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- |
| surfaceBrandName | string | 手机品牌|
| surfaceModelName | string | 手机型号|
