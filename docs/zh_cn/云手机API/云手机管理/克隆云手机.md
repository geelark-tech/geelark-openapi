## 接口说明

- 生成相同型号的全新云手机，保留国家、时区、语言、GPS信息，应用和数据不会保留

## 请求URL

- `https://openapi.geelark.cn/open/v1/phone/clone`


## 请求方法
- POST


## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/云手机/接口调用说明.md)）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
|envId|是|string|要克隆的云手机id|
|amount|是|integer|克隆数量，范围1-100|
|groupId|否|string|目标分组id，不填则放入未分组|
|cloneName|否|bool|是否克隆名称|
|cloneRemark|否|bool|是否克隆备注|
|cloneTag|否|bool|是否克隆标签|
|cloneProxy|否|bool|是否克隆代理|
|cloneNetType|否|bool|是否克隆网络类型|

## 请求示例
```json
{
    "envId": "590711571886417452",
	"amount": 1,
    "groupId": "590711571886417453"
}
```

## 响应体数据说明

| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- |
| ids | array[string] |克隆后的云手机id|


## 响应示例

```json
{
    "traceId": "B3DAFF64A7BD493CB1169D94A22BFC8D",
    "code": 0,
    "msg": "success",
    "data": {
        "ids": [
            "590711571886417454"
        ]
    }
}
```

| 42001 | 不存在对应的云机 |
| 43032 | 分组不存在 |
| 44002 | 套餐环境数量达到上限 |
| 44004 | 今日创建环境数量达到上限 |
| 44006 | 云手机库存不足 |
| 43038 | 设备机型已删除 |
