## 接口说明

上传应用

## 请求URL

- `https://openapi.geelark.cn/open/v1/app/upload`

## 请求方法

- POST


## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/云手机/接口调用说明.md)）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| fileUrl | 是 | string | 应用安装文件链接（仅支持apk、xapk） | https://material.geelark.cn/user-upload/495622401615203830/apk/uCeztwvXpswsHPH5WFht.apk |
| desc | 否 | string | 备注 | 应用备注 |

## 请求示例

```json
{
    "fileUrl" : "https://material.geelark.cn/user-upload/495622401615203830/apk/uCeztwvXpswsHPH5WFht.apk",
    "desc" : "app description"
}
```

## 响应体数据说明

| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- |
| taskId | string   | 任务id，用于查询上传状态  |

## 响应示例

```json
{
    "traceId": "B82825D58F85FB31B755BD6CA32A30A9",
    "code": 0,
    "msg": "success",
    "data": {
        "taskId": "1830906144634757120"
    }
}
```
