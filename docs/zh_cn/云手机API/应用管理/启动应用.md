## 接口说明

启动应用

## 请求URL

- `https://openapi.geelark.cn/open/v1/app/start`

## 请求方法

- POST


## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/云手机/接口调用说明.md)）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| envId | 是 | string | 云手机环境id | 1809135651036667904 |
| appVersionId | 否 | string | 应用版本id(应用版本id/应用包名两者必须有其一) | 1793552962140770305 |
|packageName| 否|string|应用包名(应用版本id/应用包名两者必须有其一) |com.zhiliaoapp.musically|

## 请求示例

```json
{
    "envId" : "1809135651036667904",
    "appVersionId" : "1793552962140770305"
}
```


## 响应示例

```json
{
    "traceId": "123",
    "code": 0,
    "msg": "success"
}
```

## 错误码

以下为接口特定错误码，其他错误码请参考[云手机错误码](../../错误码/云手机错误码.md)

| 错误码 | 说明 |
| --- | --- |
| 42001 | 不存在对应的云手机 |
| 42002 | 云手机不处于运行状态 |
| 42005 | 未安装对应的app |
| 42003 | 正在安装对应的app |
