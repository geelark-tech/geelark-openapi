## 接口说明
查询素材



## 请求URL


- `https://openapi.geelark.cn/open/v1/material/search`


## 请求方法


- POST



## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/云手机/接口调用说明.md)）

## 请求参数


| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| page | 否 | integer | 页码 | 参考请求示例 |
| pageSize | 否 | integer | 每页条数（最大200） | 参考请求示例 |
| fileName | 否 | string | 搜索文件名 | 参考请求示例 |
| tagsId | 否 | array[string] | 搜索标签id | 参考请求示例 |
| source | 否 | integer | 来源 0-上传，1-AI剪辑 2百度云盘 3GhostCut 4GoogleDrive 5图生视频 | 参考请求示例 |
| fileType | 否 | array[integer] | 文件类型 1-图片，2-视频 | 参考请求示例 |
| ids | 否 | array[string] | id数组，数组最大长度为100 | ["5213214343124321"] |



## 请求示例
```json
{
    "fileType" : [1],
    "fileName" : "demo",
    "tagIds" : ["569577514586891738"],
    "source" : 1,
    "page" : 1,
    "pageSize" : 50,
    "ids": ["608127302118696420"]
}
```

## 响应体数据说明


| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- 
| total | integer | 总条数 |
| page | integer |当前页码 |
| pageSize | integer | 当页条数 |
| list | list | 素材数据 |


## list 响应体数据说明


| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- 
| id | integer | 素材id |
| createdTime | integer |创建时间，秒级时间戳 |
| fileName | string | 素材名 |
| fileSize | integer | 素材大小 byte |
| fileUrl | string | 素材链接 |
| fileType | integer | 素材类型  1-图片，2-视频 |
| width | integer | 宽 |
| height | integer | 高 |
| source | integer | 来源 0-上传，1-AI剪辑 2百度云盘 3GhostCut 4GoogleDrive 5图生视频 |
| tags | tags | 标签数据 |
| userName | string | 上传用户名 |


## tags响应体数据说明


| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- 
| id | integer | 标签id |
| name | integer |标签名 |
| color | integer | 标签颜色 0白 1红 2蓝 3绿 4黄 5紫 |
