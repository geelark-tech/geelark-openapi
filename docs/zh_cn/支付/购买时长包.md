## 接口说明

购买时长包，请确保余额充足，否则可能会导致购买失败。

## 请求URL

- `https://openapi.geelark.cn/open/v1/pay/timeAddOn/buy`

## 请求方法

- POST


## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../使用指南/云手机/接口调用说明.md)）

## 请求参数

| 参数名       | 必选   |     类型   |    说明    |示例|
| ----------- | -------| -----------|----------- |--------- |
|minutes|是|integer|购买时长 | 2000 |
|promoCode|否|string|优惠码| PromoCode |

购买时长minutes可选值：
2000 / 5000 / 10000 / 20000 / 50000 / 100000 / 200000 / 500000 / 1000000 / 2000000 / 5000000 / 10000000 

## 请求示例

```json
{
    "minutes": 2000,
    "promoCode" : "GeeLark666"
}
```

## 响应示例

```json
{
    "traceId": "A3889654BA84B91CBABF8535B83AEABB",
    "code": 0,
    "msg": "success"
}
```
