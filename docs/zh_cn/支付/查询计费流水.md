## 接口说明

- 查询计费流水

## 请求URL

- `https://openapi.geelark.cn/open/v1/billing/transaction/detail`

## 请求方法

- POST

## 请求参数

| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| id | 否 | string | 指定云手机id，不传则获取所有 | "612451567282427943" |
| startAt | 否 | integer | 筛选开始时间，秒级时间戳（目前仅支持搜索最近3天内的数据） | 1774593838 |
| endAt | 否 | integer| 筛选结束时间，秒级时间戳（目前仅支持搜索最近3天内的数据）|1774593838|
| limit | 否 | integer | 获取数量限制，默认100，最大1000 |1 |
| lastFlowId | 否 | string | 上一次请求返回的lastFlowId，用于获取下一页数据 | "612476158453291064" |

## 请求示例

```json
{
	"id": "612451567282427943",
	"limit" : 10,
	"lastFlowId": "612476158453291064",
	"startAt" : 1774593838,
	"endAt": 1774593840
}
```

## 响应体数据说明

| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- |
| id | string | 流水id |
| envId | string | 云手机id |
| type | integer | 类型，1-云机使用 2-RPA |
| chargeType | integer | 计费类型 1-积分 2-余额 3-赠送金 4-时长包 5-免费时长 6-包月 7-并发数 8-扣费封顶|
| amount | float | 数额 |
| usedTime | integer | 使用时长，分钟 |
| createdTime | integer | 流水时间，秒级时间戳 |
| lastFlowId | string | 最后一个流水id，用于获取下一页数据 |
