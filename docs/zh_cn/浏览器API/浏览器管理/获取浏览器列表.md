## 接口说明


查询已创建的环境信息，包含代理信息、代理ID等。



## 请求URL


- `http://localhost:40185/api/v1/browser/list`


## 请求方法



- POST




## 鉴权

所有请求均为 `POST`，请求头需设置 `Content-Type: application/json`。

必需请求头：

- `traceId`：Version 4 UUID（建议大写）
- **Token 模式：** `Authorization: Bearer YOUR_API_TOKEN`
- **Key 模式：** `appId`、`traceId`、`ts`、`nonce`、`sign`（见 [接口调用说明](../../使用指南/浏览器/接口调用说明.md)）

## 请求参数



| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| page | 否 | integer | 页码，最小为1，不填默认为1 | 1 |
| pageSize | 否 | integer | 每页多少条数据，最小为1，最大为100，不填默认为10 | 10 |
| ids | 否 | array[string] | 环境id，最大为100个，为空才使用分页参数 | [“5213214343124321”] |
| serialName | 否 | string | 环境名称 | myEnv |
| remark | 否 | string | 备注 | myRemark |
| groupName | 否 | string | 分组名 | myGroup |
| tags | 否 | array[string] | 标签名称数组 | ["myTag"] |



## 请求示例



```json
{
 "page": 1,
 "pageSize": 10
}
```

## 响应体数据说明



| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| total | integer | 数据总数 |
| page | integer | 当前页码 |
| pageSize | integer | 每页多少条数据 |
| items | array[BrowserApiSearchSimpleItem] | 数据列表 |


### 浏览器数据 BrowserApiSearchSimpleItem


| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 环境id |
| serialName | string | 环境名称 |
| serialNo | string | 环境编号 |
| group | EnvGroup | 环境分组 |
| remark | string | 备注 |
| tags | array[EnvTag] | 环境标签 |
| proxy | EnvPhoneListProxy | 代理信息 |
| accountInfo | BrowserApiSearchSimpleAccount | 账号信息 |
| simulateInfo | BrowserApiSearchSimpleSimulate | 仿真信息 |


### 环境分组 EnvGroup


| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 环境分组id |
| name | string | 环境分组名 |
| remark | string | 环境分组备注 |


### 环境标签 EnvTag


| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 标签名 |
