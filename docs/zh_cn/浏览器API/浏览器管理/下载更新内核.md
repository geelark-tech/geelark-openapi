## 接口说明

下载或更新指定内核到最新版本。
> v4.3.8及以上版本可用


## 请求URL

- `http://localhost:40185/api/v1/browser/updateKernels`

## 请求方法


- POST






## 请求参数


| 参数名 | 必选 | 类型 |  示例 | 说明
| --- | --- | --- | --- | --- |
| kernel_version | 是 | string | "143" |浏览器内核版本|


## 请求示例


```json
{
    "kernel_version":"143",
}
```


## 响应示例


```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "status": "complete",
        "progress": 0
    }
}
```
