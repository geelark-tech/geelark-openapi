## 接口说明

用于启动指定 ID 的浏览器环境，支持同步返回与异步 WebHook 回调通知。

## 请求URL

- `http://localhost:40185/api/v1/browser/start`

## 请求方法


- POST



## 请求参数


| 参数名 | 必选 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| id | 是 | string | 浏览器id | 539893235657500146 |
| webhook | 否 | string | 回调URL，浏览器启动完成后会发送通知 | http://localhost:3001 |

## WebHook回调

### 触发时机
浏览器启动任务结束后触发。

### 回调地址
通过请求参数`webhook`指定。

### 回调方法
POST

### 回调请求头
```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer AZ4LY7J33IY5NQ7IYVQ5D5BR7B6GNWSG" // 与API请求的Authorization头相同
}
```

### 回调数据
```json
{
  "event": "browser_start",
  "timestamp": 1776147008407,
  "data": {
    "id": "612342716134614477",
    "status": "success",
    "debugPort": 11019,
    "ipCheckPass": true
  }
}
```

## 请求示例


```json
{
  "id": "612342716134614477",
  "webhook": "http://localhost:3001"
}
```


## 响应示例


```json
{
  "code": 0,
   "msg": "success",
   "data": {
       "debugPort": 11001
   }
}
```




### 回调参数说明
| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| event | string | 事件类型，固定为browser_start |
| timestamp | number | 回调发送时间戳 |
| data.id | string | 浏览器ID |
| data.status | string | 启动状态：success/failed |
| data.debugPort | number | 浏览器调试端口 |
| data.ipCheckPass | boolean | 代理检测是否通过 |



## 错误码

| --- | --- |
| -1 | 启动失败 |
| 43007 | 环境有其他人在使用 |
| 43008 | 打开环境数达到上限 |
| 46003 | 该环境不在套餐内 |
| 90002 | 该环境不存在 |
| 90003 | 磁盘空间不足 |
