## 接口说明

设置浏览器书签，浏览器环境启动后自动应用书签。


## 请求URL

- `http://localhost:40185/api/v1/browser/setBookmark`

## 请求方法

- POST

## 请求参数


| 参数名 | 必选 | 类型 |  示例 | 说明
| --- | --- | --- | --- | --- |
| browserBookmark | 是 | BrowserBookmark | 参考请求示例 |浏览器书签|

### BrowserBookmark 浏览器书签

| 参数名 | 必选 | 类型 |  示例 | 说明
| --- | --- | --- | --- | --- |
|type|是|integer|2|书签类型，0-不设置，1-上传文件，2-手动创建|
|fileAddr|否|string|https://storage.com/bookmark.html|书签html文件地址|
|text|否|string|参考请求示例|手动创建书签内容，多个书签用换行符\n分隔，支持格式:</br>文件夹::名称::网址</br>名称::网址</br>网址|


## 请求示例


```json
{
    "browserBookmark": {
        "type": 2,
        "fileAddr": "",
        "text": "http://a.com\nhttp://b.com"
    }
}
```


## 响应示例


```json
{
    "traceId": "123456ABCDEF",
    "code": 0,
    "msg": "success"
}
```
