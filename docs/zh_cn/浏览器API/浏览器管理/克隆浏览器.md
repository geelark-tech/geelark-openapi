## 接口说明

- 生成相同的操作系统、高级设置的全新浏览器

## 请求URL

- `http://localhost:40185/api/v1/browser/clone`


## 请求方法
- POST

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
|envId|是|string|要克隆的浏览器id|
|amount|是|integer|克隆数量，范围1-100|
|groupId|否|string|目标分组id，不填则放入未分组|
|cloneName|否|bool|是否克隆名称|
|cloneRemark|否|bool|是否克隆备注|
|cloneTag|否|bool|是否克隆标签|
|cloneProxy|否|bool|是否克隆代理|
|cloneCookie|否|bool|是否克隆Cookie|
|cloneAccount|否|bool|是否克隆账号信息|

## 请求示例
```json
{
    "envId": "590711571886417452",
	"amount": 1,
    "groupId": "590711571886417453"
}
```

## 响应体数据说明

| 参数名       |     类型   |    说明    |
| ----------- | -----------|----------- |
| ids | array[string] |克隆后的浏览器id|


## 响应示例

```json
{
    "traceId": "B3DAFF64A7BD493CB1169D94A22BFC8D",
    "code": 0,
    "msg": "success",
    "data": {
        "ids": [
            "590711571886417454"
        ]
    }
}
```
