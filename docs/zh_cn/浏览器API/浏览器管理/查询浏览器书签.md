## 接口说明

查询浏览器书签设置，不需要传请求体


## 请求URL

- `http://localhost:40185/api/v1/browser/getBookmark`

## 请求方法

- POST

## 响应体数据说明

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| browserBookmark | BrowserBookmark |浏览器书签|

### BrowserBookmark 浏览器书签

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
|type|integer|书签类型，0-不设置，1-上传文件，2-手动创建|
|fileAddr|string|书签html文件地址|
|text|string|手动创建书签内容，多个书签用换行符\n分隔，支持格式:</br>文件夹::名称::网址</br>名称::网址</br>网址|


## 响应示例


```json
{
	"traceId":"123456ABCDEF",
	"code":0,
	"msg":"success",
	"data":{
		"browserBookmark":{
			"type":2,
			"fileAddr":"",
			"text":"http://a.com\nhttp://b.com"
		}
	}
}
```
